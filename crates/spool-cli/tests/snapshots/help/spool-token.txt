Make, list and revoke the tokens of callers that are not people

Usage: spool token [OPTIONS] <COMMAND>

Commands:
  add     Make a token, and print it
  list    List the tokens
  revoke  Revoke a token: the server no longer accepts it
  help    Print this message or the help of the given subcommand(s)

Options:
      --store <PATH>  The store's database file; the tokens are in the accounts file beside it [env:
                      SPOOL_STORE]
  -h, --help          Print help (see more with '--help')

Output options:
  -o, --output <OUTPUT>  Output format [default: table] [possible values: table, json, ndjson, csv]
      --json             Shorthand for `--output json`

Global options:
      --color <WHEN>  When to use colour [default: auto] [possible values: auto, always, never]
  -q, --quiet         Print only the result and errors: no hints or progress
