Make, list and revoke the tokens of callers that are not people

Usage: spool token [OPTIONS] <COMMAND>

Commands:
  add     Make a token, and print it
  list    List the tokens
  revoke  Revoke a token: the server no longer accepts it
  help    Print this message or the help of the given subcommand(s)

Options:
      --store <PATH>  The store's database file; the tokens are in the accounts file beside it [env:
                      SPOOL_STORE]
      --json          Print the tokens as JSON
  -h, --help          Print help (see more with '--help')
